# FT_41_45_81_49.trace_mode

It is possible to trace `protoprimer` execution using standard `trace` module:

*   instead of simply running [entry_script][FT_75_87_82_46.entry_script.md]:

    ```shell
    ./prime
    ```

*   run this:

    ```shell
    python -m trace ./prime
    ```

However, because `protoprimer` restarts [python_executable][FT_72_45_12_06.python_executable.md],
subsequent `python` interpreters start without extra args.

To re-introduce the extra args on `python` restarts, set `PROTOPRIMER_TRACE_EXECUTION` to `true`:

```sh
PROTOPRIMER_TRACE_EXECUTION=true python -m trace --trace ./prime
```

Trace output goes to `stderr`.

To capture generated output into files, use I/O redirection -
see [debugging_and_troubleshooting][UC_17_31_62_27.debugging_and_troubleshooting.md].
