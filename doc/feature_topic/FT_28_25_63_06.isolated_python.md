# FT_28_25_63_06.isolated_python

## Intro

When `python` imports non-standard module, it must import it from the dedicated `venv`.

The `protoprimer` is designed to work in an isolated environment sharing no non-standard packages.
This allows multiple independent deployments on the same host for the same user using different versions.

## Approach

The general approach is to always switch `python` to isolated mode (see `python -I`).
