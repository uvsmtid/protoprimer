
# FT_18_38_32_22.script_dir

`script_dir` is the `dirname` of the absolute path to the currently running script (without script `basename`).

This is the base path that allows referencing any other path as relative to it.

This combination allows accessing reliably any other file within user code:
*   Every script is supposed to know its relative path within the deployed filesystem.
*   Every script will know its absolute path from the runtime.

The `script_dir` is the central concept for the `protoprimer` where
[entry_script][FT_75_87_82_46.entry_script.md]-s specify their relative paths to
[proto_kernel][FT_87_17_49_36.proto_kernel.md] which becomes abosolute
by combining it with `script_dir` as the base.
