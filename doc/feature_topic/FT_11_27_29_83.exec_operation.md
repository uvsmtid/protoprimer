# FT_11_27_29_83.exec_operation

## Intro

Exec operation refers to what [proto_code][FT_90_65_67_62.proto_code.md] is invoked for.

It changes how the script traverses the [state_dependency][FT_68_54_41_96.state_dependency.md]
and affects how each state is bootstrapped.

Exec operations are supposed to be selected via CLI:

```sh
./prime -h
```
