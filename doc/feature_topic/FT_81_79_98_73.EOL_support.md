# FT_81_79_98_73.EOL_support

Cases where supporting both ends of version ranges at once hits mutually exclusive formats.

Related: [supported_python_versions][FT_84_11_73_28.supported_python_versions.md].

## `setuptools` `license` field format

*   `setuptools>=77.0.0`:

    `project.license` TOML table (e.g. `license = { text = "MIT" }`) is deprecated.

*   `setuptools<77.0.0`:

    SPDX expression string (e.g. `license = "MIT"`) is rejected.

Resolved with `dynamic = ["license"]` in `pyproject.toml` and a `setuptools.__version__` check in `setup.py`.
