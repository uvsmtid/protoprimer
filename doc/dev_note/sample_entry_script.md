
Script `./cmd/start_app_example` delegates execution to
function `custom_start_app_main` inside
module `local_doc.cmd_start_app_example` implemented
in `./src/local_doc/main/local_doc/cmd_start_app_example.py` file.

Normally,
`./cmd/start_app_example` (inside `./cmd` dir but without `cmd_` prefix in extension-less file)
is implemented by
`cmd_start_app_example.py` (inside one of the projects, with `cmd_` prefix in `*.py` file).
