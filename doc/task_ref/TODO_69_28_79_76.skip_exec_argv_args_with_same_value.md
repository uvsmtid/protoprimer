## What the code does

`switch_python` restarts `python` (via `os.execve`) with `exec_argv`:

*   `next_python_path`;
*   `-I` ([isolated_python][FT_28_25_63_06.isolated_python.md]) - consumed by `python` itself,
    it is not in `sys.argv` of the next process (it only sets `sys.flags.isolated`);
*   optionally `-m trace --trace` ([trace_mode][FT_41_45_81_49.trace_mode.md]);
*   all of the current `sys.argv`.

The process may be restarted several times (each `StateStride` switch), so the same args pass through each restart.
