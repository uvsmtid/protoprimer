Reduce the "surface" of public interfaces in [primer_kernel.py][primer_kernel.py]
to the minimum necessary for the other scripts in this repo which use `protoprimer`,
so that internal implementation details stop being usable (and therefore breakable) from outside the module.

Related: [TODO_36_76_61_27.semver_backward_compatibility_testing.md][TODO_36_76_61_27.semver_backward_compatibility_testing.md]
(this plan is the "ongoing effort" referenced there, see "Decisions on the findings" and `U7`).

## Why

*   `primer_kernel.py` has no `__all__`: every name without a leading underscore is importable and, per `griffe`
    (the tool `TODO_36_76_61_27` uses for API compatibility checks), part of the public API.

*   Most of the module is the bootstrap state graph: ~160 concrete node classes
    (`Bootstrapper_state_*`, `Factory_state_*`, `Base_state_*`) plus ~20 standalone helper functions
    (Python/venv probing, path helpers, ...). None of them are imported by any other script in this repo -
    they exist to be wired into `StateGraph` internally and are only reached by `protoprimer`'s own tests.

*   Today a rename of any of these breaks `old_tests_on_new_changes`/`griffe` in `TODO_36_76_61_27` even though
    no real consumer is affected (`TODO_36_76_61_27`'s spike ex_1 saw 55 `griffe` findings between a baseline
    and the current tree, most of them noise from names that were never meant to be public - see its `U7`).
    Shrinking the surface now means fewer false positives once the `griffe` check (`TODO_36_76_61_27` step 5) is relied upon.

*   `TODO_36_76_61_27` already decided this is accepted for now and is "a separate ongoing effort" - this file is that effort.

## Scope

*   Only `src/protoprimer/main/protoprimer/primer_kernel.py`.

*   "Other scripts limited to this repo" = every package in this repo that imports `protoprimer.primer_kernel`
    other than `protoprimer`'s own test suite (`src/protoprimer/test/`):
    `local_repo`, `local_doc`, `local_test`, `local_contract_compatibility`, `metaprimer`, and the generated/committed
    `src/proto_code/proto_kernel.py` (a copy of this same module, so it needs nothing beyond what `primer_kernel.py` itself keeps).
    `protoprimer`'s own tests are explicitly exempt (decided in `TODO_36_76_61_27`: internal tests may use internals;
    a rename there is a mechanical update, not a compatibility break).

*   Config/CLI/env var wire-level contracts (config file keys, CLI args, env var names) are **not** in scope here -
    those are covered by `TODO_36_76_61_27`'s `pydantic`/`cliff`/env-var-name checks.
    This plan is only about which **Python names are importable** from `primer_kernel.py`.

## Method (decided)

Use a leading underscore, `griffe`'s own public/private convention, already used in this file for some helpers
(`_create_parent_argparser`, `_get_shell_driver`, `_is_blank_line`, `_PrimerFileLogFormatter`, ...).
No `__all__` list: it does not stop a direct `from protoprimer.primer_kernel import SomeInternalClass`,
and `griffe` itself keys off the underscore, not `__all__`.
