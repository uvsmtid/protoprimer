## Strategy (decided)

The default is private: every name ends up `KEEP_PRIVATE` unless it is explicitly decided as `KEEP_REQUIRED` or `KEEP_PUBLIC`.
A name stays non-private only after an explicit decision, never by default or by omission.

There are three categories (see "Required API" in [FT_78_72_23_04.backward_compatibility.md][FT_78_72_23_04.backward_compatibility.md]):

*   `KEEP_PRIVATE` - hidden within `protoprimer` (leading underscore, not checked).
*   `KEEP_REQUIRED` - used by `protoprimer` itself across kernel versions (e.g. via `getattr(imported_kernel, ...)`):
    leading underscore (not for clients/users), but checked for availability by `griffe`.
*   `KEEP_PUBLIC` - used by clients/users (no leading underscore, checked).

When a class is `KEEP_PUBLIC`, each of its members is reviewed separately (private by default).
A class with a leading underscore (`KEEP_PRIVATE` or `KEEP_REQUIRED`) needs no member review:
its members are already outside the public interface (for `KEEP_REQUIRED`, `griffe` checks all of its non-underscore members).

The `**required**` tag is only an assumption (a consumer in "## Scope" imports the name today), not an approved decision:
every `required` item still has to be reviewed to decide whether it is really `KEEP_PUBLIC`.
Until that review, `required` items stay at `decision_status: TBD`.

## Method (decided)

Use a leading underscore, `griffe`'s own public/private convention, already used in this file for some helpers
(`_create_parent_argparser`, `_get_shell_driver`, `_is_blank_line`, `_PrimerFileLogFormatter`, ...).
No `__all__` list: it does not stop a direct `from protoprimer.primer_kernel import SomeInternalClass`,
and `griffe` itself keys off the underscore, not `__all__`.

`_Node_state_*` (was `Bootstrapper_state_*`), `_BaseNode_state_*` (was `Base_state_*`),
`_Factory_state_*` (was `Factory_state_*`).

## Tracking decisions

Each `###` subsection below carries two separate things, on separate lines:

*   `decision_status:` (first line of the body) - the **actual decision** for that name, tracked independently
    of the proposal. Possible values:

    *   `TBD` - not decided yet (every item starts here).
    *   `KEEP_PRIVATE` - decided: this name ends up private (already-private names stay so;
        a currently-public `privatize`/`pending`/`unclassified` name is renamed with a leading underscore).
    *   `KEEP_REQUIRED` - decided: this name is not for clients/users but `protoprimer` itself needs it across versions;
        it gets a leading underscore and is checked by `griffe` (marked `public`) anyway.
        NOTE: unrelated to the `**required**` proposal tag below (which only means "has an in-scope consumer").
    *   `KEEP_PUBLIC` - decided: this name stays public as-is.

*   The bold tag below it (`**required**`, `**privatize**`, `**pending**`, `**unclassified**`, or
    `*(already private)*`) - the **proposal** this plan's scan arrived at, with the evidence behind it.
    It is a suggestion to review against, not the decision: a `privatize` proposal can still end up
    `KEEP_PUBLIC` if review finds a reason to keep it public, and vice versa.
