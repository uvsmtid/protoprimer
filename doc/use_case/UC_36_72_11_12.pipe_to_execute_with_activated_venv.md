# UC_36_72_11_12.pipe_to_execute_with_activated_venv

User should be able to execute `shell` commands in activated `venv`.

There are two (mutually exclusive) ways via the `shell` sub-command - see [venv_shell][FT_99_89_51_06.venv_shell.md].

*   Specifying `--command`/`-c` followed by a string arg (the string is to be interpreted by the `shell`).

    ```sh
    ./proto_kernel.py shell --command "exit 42"
    ```

*   Pipe-redirect output of a command to `stdin`.

    ```sh
    echo "exit 42" | ./proto_kernel.py shell
    ```

    `protoprimer` simply delegates reading the pipe to the `shell` -
    if the `shell` does not do that, piped commands will not be executed.
