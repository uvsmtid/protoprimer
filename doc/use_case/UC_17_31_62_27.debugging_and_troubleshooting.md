# UC_17_31_62_27.debugging_and_troubleshooting

`protoprimer` restarts [python_executable][FT_72_45_12_06.python_executable.md] progressively
to switch from **wild** `python` to **required** `python`,
then runs [DAG_extension][FT_74_10_40_33.DAG_extension.md]-s.

To debug that sequence, there are few approaches.

## Log level

Increase the log level for the [entry_script][FT_75_87_82_46.entry_script.md]:

```shell
./prime -v
./prime -vv
./prime -vvv
```

This works only for [boot_env][FT_85_17_35_21.boot_env.md]
due to required [CLI_compatibility][FT_62_88_55_10.CLI_compatibility.md].
See also [boot_vs_start][FT_58_74_37_70.boot_vs_start.md].
